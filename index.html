Questions

Why buy an upgraded computer?

Many popular models are only sold in base configurations with limited memory and storage. We offer the same machines with 16GB or 32GB of memory and up to 2TB of storage, so you get the configuration you actually need.

Which marketplace should I buy from?

Whichever you prefer. Orders, payments, and returns are handled through that marketplace, so you're covered by its buyer policies.

Where do you ship from?

All orders ship from Plainfield, New Jersey.

How much memory and storage do I need?

For everyday use, 16GB of memory and 512GB of storage is a comfortable fit. Choose 32GB if you edit video, work with large files, or run lots of programs at once, and 1TB or more if you keep big photo, video, or game libraries.
